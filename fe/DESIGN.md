## Overview

Modern, data-dense SaaS dashboard aesthetic for Essential featuring vibrant electric blue accents (#256EFF), crisp neutral surfaces (#FFFFFF), light gray canvas (#F7F7F7), subtle borders (#E4E4E4), and pill badges.

## Management Page Layout

Context cho các chức năng quản lý: thứ tự phân cấp `page header → statistics → manager table`.

## Style Foundations

- **Visual style:** modern SaaS dashboard
- **Typography scale:** 12/14/16/18/24/30/36
- **Typography fonts:** primary=Inter, display=Inter, mono=JetBrains Mono
- **Typography weights:** 400, 500, 600, 700
- **Color palette:** primary, secondary, neutral, success, warning, danger, status
- **Spacing scale:** 4/8/12/16/24/32

## Colors

- **Primary (#256EFF):** Brand electric blue for primary buttons, active toggles, chart series, logo icon, and badges.
- **Secondary (#6B7280):** Neutral gray for icons, secondary elements, and borders.
- **Success (#15A34A):** Active status dots, positive trend metrics, and positive sparklines.
- **Warning (#F97316):** Pending status indicators and caution alerts.
- **Danger (#DC2626):** Negative metric indicators, downward sparklines, and error states.
- **Surface (#FFFFFF):** Cards, headers, modals, and table containers.
- **Background (#F7F7F7):** Canvas background framing cards and content sections.
- **Text (#1A1A1A):** High-contrast primary headings, table values, and metrics.
- **Text Muted (#71717A):** Subtitles, meta info, table column headers, and email addresses.
- **Border (#E4E4E4):** Card outlines, table dividers, button strokes, and search inputs.
- **Neutral (#FFFFFF):** Derived from the surface token for official format compatibility.
- **Dashboard Shell (#113163):** Navigation header and sidebar background for the authenticated dashboard shell.
